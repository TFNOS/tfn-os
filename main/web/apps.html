An installed app is a file on the board or on the SD card. It opens from the menu as any other app. OPEN opens it on the board now. MOVE puts it in the other place. REMOVE deletes its files (its saved scores stay).

Install an app file

Select the files of one app for this board kind (?): manifest.txt, app.elf, icon.bin and sig. They come from the manager store, or from sdk/out/<app>/<kind>/ of the SDK.

Developer mode

Only for app development. A file with no signature can be anything: keep it off on boards that you do not test on. This page can only turn it off: turn it on at the board (SETUP > DEVELOPER MODE, then tap TURN ON with your finger) or with the USB console (apps dev 1).
