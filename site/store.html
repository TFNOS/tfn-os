Apps for your board

Games and tools for TFN OS. They are free, they have the signature of the TFN OS store, and an install takes one click over USB.

Connect your board

Connect the board to this computer with a USB cable. The board must run TFN OS (install it). The page then shows the apps for your board and installs them.

This browser cannot use USB. Use Chrome or Edge on a computer to install with one click. Here you can look at the apps and save their signed files.

  • The page gets the list of the apps and checks its signature.

Why you can trust these files

The TFN OS store signs each app with its key (ECDSA P-256). Your board checks that signature before it installs an app, against the store key that is in TFN OS itself. A changed or damaged file never goes on the board. This page also checks the signature of the app list with the same key, and the SHA-256 of each file before it uses it.

Other ways to install an app
  1. The STORE app of the board. On a board with WiFi, open STORE in the menu and tap an app.
  2. The web page of the board. Save the signed file of the app (the Download button in the window of the app) and unzip it. SETUP > WEB PAGE on the board shows its address. Open http://<the board address>/apps on a computer in the same network. Under "Install an app file", select all the files of the app, and click Install.
  3. The SD card. Copy the folder with the files of the app to the SD card. Open the folder in FILES on the board, and tap INSTALL.
