The apps

Free apps for TFN OS. Each app file has the signature of the TFN OS store. Your board checks the signature before it installs the app.

Store release , store key . The page checked the signature of the list and checks the SHA-256 of each file before you save it.

1Choose your board

Your board must run TFN OS. To install it, use the install page.

2The apps

    3Install the app on the board

    Unzip the file that you saved. It holds the files of the app: manifest.txt, app.elf, icon.bin and sig. Then use one of these ways:

    1. The web page of the board. Connect the board to your WiFi. SETUP > WEB PAGE on the board shows its address. On a computer or a phone in the same network, open http://<the board address>/apps. Under "Install an app file", select all the files of the app, and click Install.
    2. The SD card. Copy the folder with the files of the app to the SD card. Put the card into the board, open the folder in FILES, and tap INSTALL.

    The app is then in the menu of the board. The board refuses a file with no good signature, and a file for another board kind.
