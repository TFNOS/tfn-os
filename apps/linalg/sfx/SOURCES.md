# The sound effects of LINEAR ALGEBRA

All of them have the CC0 licence (public domain). They come from the PC library of the project
(not in this tree), made from these packs. `la_sfx.c` has them as C data (a board with no SD card plays them
too): `python libs/tfsfx/mk_sfx_c.py apps/linalg/sfx apps/linalg/la_sfx LA page pageb tick open pick`.

| File | What | Pack | Page |
|---|---|---|---|
| page.mp3 | the next step | Kenney Casino Audio (card-slide-1.ogg) | https://kenney.nl/assets/casino-audio |
| pageb.mp3 | the step before | Kenney Casino Audio (card-slide-2.ogg) | https://kenney.nl/assets/casino-audio |
| tick.mp3 | a number of the example changes | Kenney Interface Sounds (click_004.ogg) | https://kenney.nl/assets/interface-sounds |
| open.mp3 | a chapter opens | Kenney Interface Sounds (open_002.ogg) | https://kenney.nl/assets/interface-sounds |
| pick.mp3 | a number is chosen for a change | Kenney Interface Sounds (toggle_002.ogg) | https://kenney.nl/assets/interface-sounds |
