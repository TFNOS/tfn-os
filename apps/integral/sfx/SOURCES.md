# The sound effects of INTEGRALS

All of them have the CC0 licence (public domain). They come from the PC library of the project
(not in this tree). `ig_sfx.c` has them as C data (the boards with no SD card play them too):
`python libs/tfsfx/mk_sfx_c.py apps/integral/sfx apps/integral/ig_sfx IG step open done back`.

| File | What | Pack | Page |
|---|---|---|---|
| step.mp3 | the next step or the step before | Kenney Interface Sounds (click_004.ogg) | https://kenney.nl/assets/interface-sounds |
| open.mp3 | a chapter or a lesson opens | Kenney Interface Sounds (select_003.ogg) | https://kenney.nl/assets/interface-sounds |
| done.mp3 | the last step of a lesson | Kenney Interface Sounds (confirmation_001.ogg) | https://kenney.nl/assets/interface-sounds |
| back.mp3 | back to the list | Kenney Interface Sounds (back_001.ogg) | https://kenney.nl/assets/interface-sounds |
